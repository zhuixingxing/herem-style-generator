# Hérem Style Generator

> 将照片转化为插画风格的在线工具，基于 Stable Horde 社区 GPU 免费生成。

🌐 **在线地址：** https://herem-style-generator.vercel.app

---

## 功能介绍

上传一张照片，选择插画风格，AI 会将其转化为对应风格的插画。支持以下 8 种风格：

| 风格 | 特点 |
|------|------|
| Thibaud Hérem | 手绘建筑水彩，精细线条，暖金与深蓝色调 |
| Studio Ghibli | 吉卜力动画风，手绘赛璐珞，自然光感 |
| Van Gogh | 后印象派油画，厚涂笔触，强烈色彩 |
| Monet | 法式印象派，柔和笔触，水面光影 |
| 浮世绘 | 日式木版画，平涂色块，黑色轮廓线 |
| Edward Hopper | 美式写实油画，戏剧性光影，孤寂气氛 |
| 漫画风格 | 美式漫画，粗黑轮廓，网点纹理 |
| 扁平插画 | 现代矢量风，几何色块，简洁设计感 |

---

## 使用方法

1. **上传照片** — 点击上传区域或将图片拖入，支持 JPG / PNG / WEBP（最大 20MB）
2. **选择风格** — 点击下方风格卡片选择目标插画风格
3. **调节强度** — 拖动滑块控制风格渲染程度（30%–70%），数值越高风格越强
4. **生成插画** — 点击「生成插画」按钮，等待约 30–120 秒（取决于排队情况）
5. **保存结果** — 生成完成后可点击「复制」或「下载」保存图片

> **提示：** 建筑、街景、城市风景的效果最佳；人物照片也可使用。

## 安装为手机 App（iOS）

本工具支持 PWA，可以安装到 iPhone 主屏幕，像原生 App 一样全屏运行：

1. 用 **Safari** 打开 https://herem-style-generator.vercel.app
2. 点击底部工具栏的 **分享按钮**（方块加箭头图标）
3. 向下滑动，点击 **「添加到主屏幕」**
4. 确认名称后点击 **「添加」**

安装后图标会出现在主屏幕，打开即为全屏沉浸式体验。

## 技术说明

- **生成引擎：** [Stable Horde](https://stablehorde.net) — 社区共享 GPU，匿名免费使用
- **模型：** Stable Diffusion img2img（风格迁移模式）
- **分辨率限制：** 匿名用户最大 576×576，步数 25
- **历史记录：** 保存在浏览器本地（localStorage），不上传任何图片到服务器
- **部署：** Vercel 静态托管，纯前端，无后端服务器

## 常见问题

**Q: 生成失败或等待很久？**  
A: Stable Horde 是社区资源，高峰期队列较长，可以稍等重试。

**Q: 复制图片失败？**  
A: iPhone 上点击「复制」会弹出系统分享菜单，选择「拷贝照片」即可；「下载」会弹出分享菜单，选择「存储图像」保存到相册。

**Q: 历史记录消失了？**  
A: 历史记录存储在浏览器本地，清除浏览器数据后会丢失。
