# Hérem Style Generator

> 将照片转化为插画风格的在线工具，基于 Stable Horde 社区 GPU 免费生成。

🌐 **在线地址：** https://herem-style-generator.vercel.app

---

## 功能介绍

上传一张照片，选择插画风格，AI 会将其转化为对应风格的插画。支持以下 8 种风格，每种风格均有独立调优的生成参数：

| 风格 | 特点 | cfg_scale | 采样器 |
|------|------|-----------|--------|
| Thibaud Hérem | 手绘建筑水彩，精细线条，暖金与深蓝色调 | 7 | k_euler_a |
| Studio Ghibli | 吉卜力动画风，手绘赛璐珞，自然光感 | 8 | k_euler_a |
| Van Gogh | 后印象派油画，厚涂笔触，强烈色彩 | 9 | k_euler_a |
| Monet | 法式印象派，柔和笔触，水面光影 | 7 | k_euler_a |
| 浮世绘 | 日式木版画，平涂色块，黑色轮廓线 | 10 | k_euler |
| Edward Hopper | 美式写实油画，戏剧性光影，孤寂气氛 | 8 | k_euler_a |
| 漫画风格 | 美式漫画，粗黑轮廓，网点纹理 | 10 | k_euler |
| 扁平插画 | 现代矢量风，几何色块，简洁设计感 | 9 | k_euler |

## 人像智能优化

上传照片后，系统会自动检测是否含有人像：

- **检测方式：** 优先使用浏览器原生 Face Detection API；不支持时降级为 canvas 肤色像素分析（Peer RGB 规则 + 人脸区域集中度双重校验）
- **触发条件：** 皮肤色像素 > 15% 且集中分布在图像中央上方（人脸典型位置）
- **优化效果：** 检测到人像后自动切换专属参数——prompt 追加面部细节词（因风格不同，如 Ghibli 追加大眼动漫特征、浮世绘追加美人绘风格），negative prompt 追加面部变形保护词，并对 denoising_strength 设置上限，防止强度过高导致面部失真

## 使用方法

1. **上传照片** — 点击上传区域或将图片拖入，支持 JPG / PNG / WEBP（最大 20MB）
2. **选择风格** — 点击下方风格卡片选择目标插画风格
3. **调节强度** — 拖动滑块控制风格渲染程度（30%–70%），数值越高风格越强
4. **生成插画** — 点击「生成插画」按钮，等待约 30–120 秒（取决于排队情况）
5. **保存结果** — 生成完成后可点击「复制」或「下载」保存图片

> **提示：** 建筑、街景、城市风景效果最佳；含人物的照片会自动启用人像优化。

## 安装为手机 App（iOS）

本工具支持 PWA，可以安装到 iPhone 主屏幕，像原生 App 一样全屏运行：

1. 用 **Safari** 打开 https://herem-style-generator.vercel.app
2. 点击底部工具栏的 **分享按钮**（方块加箭头图标）
3. 向下滑动，点击 **「添加到主屏幕」**
4. 确认名称后点击 **「添加」**

安装后图标会出现在主屏幕，打开即为全屏沉浸式体验。

> **iOS 保存图片：** 点击「复制」会弹出系统分享菜单，选择「拷贝照片」；点击「下载」选择「存储图像」可保存到相册。

## 技术说明

- **生成引擎：** [Stable Horde](https://stablehorde.net) — 社区共享 GPU
- **模型：** Stable Diffusion img2img（风格迁移模式）
- **分辨率：** 最大 576×576（Stable Horde 免费额度上限，随服务器负载动态调整）
- **步数：** 25–38 步，根据风格独立设定；使用 k_euler / k_euler_a 采样器（无步数折半惩罚）
- **历史记录：** 保存在浏览器本地（localStorage），不上传任何图片到服务器
- **部署：** Vercel 静态托管，纯前端，无后端服务器

## 常见问题

**Q: 生成失败提示"KudosUpfront"？**  
A: Stable Horde 在高峰期会临时降低免费额度上限（如从 712×712 收紧到 576×576），稍后重试即可。若频繁出现，可在 [stablehorde.net](https://stablehorde.net) 贡献算力赚取 kudos 来解除限制。

**Q: 生成等待很久？**  
A: Stable Horde 是社区资源，高峰期队列较长。可点击「取消」后重新提交，有时换个时间段排队更快。

**Q: 检测到人像但实际没有人？**  
A: 肤色检测基于色彩分析，极少数情况下暖色调画面可能误触发。可忽略该提示继续生成，对非人像照片影响很小。

**Q: 历史记录消失了？**  
A: 历史记录存储在浏览器本地，清除浏览器数据后会丢失。
